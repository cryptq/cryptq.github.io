Почему это работает

  • Индивидуальная архитектура сети и физиология дают стабильные паттерны.
  • Методы ML выделяют сочетания признаков, устойчивые в пределах субъекта.
  • SSVEP/VEP усиливают SNR и дают повторяемые спектральные пики.

Ограничения

  • Чувствительность к артефактам (движение, шум, оборудование).
  • Необходимость многосессионной валидации (test–retest).
  • Этические и юридические риски при хранении нейроданных.

Пошаговый конвейер извлечения подписи (fMRI / EEG)

fMRI — шаги

  1. fMRIPrep: motion correction, normalization, confounds extraction.
  2. Extract ROI time series (Schaefer / AAL).
  3. Compute connectivity (Pearson / partial / precision).
  4. Fisher z-transform, graph metrics, PCA/embeddings.
  5. Evaluate: identification rate, ICC, permutation test.

EEG — шаги

  1. Filter: notch 50/60Hz, bandpass 1–80Hz; ref: average.
  2. Artifact removal: ICA, channel interpolation.
  3. Features: bandpowers, coherence/PLV, SSVEP STFT, microstates.
  4. Compact signature: flatten upper-triangle, PCA/autoencoder.
  5. Evaluate: split A/B sessions, cosine NN, ROC, EER.

Кодовые фрагменты и pseudocode

# EEG bandpower (Welch)
for ch in channels:
  f,P = welch(signal[ch])
  pow = integrate(P in band)
signature = mean(pow across channels)

Рекомендации для репликации

  • Разделение по сессиям при CV, nested CV для гиперпараметров.
  • Test–retest (дни / недели / месяцы).
  • Permutation tests и explainable-AI для проверки артефактов.

Этика, безопасность и правовые риски

Нейроданные — чувствительная категория. Требуется информированное согласие, шифрование хранения, и оценка рисков (ре-идентификация, дискриминация).

Ключевые рекомендации

  1. Не храните raw EEG/fMRI без шифрования и прав доступа.
  2. Документируйте pipeline, версии ПО и QC-метрики.
  3. Ограничьте доступ и обеспечьте юридические гарантии использования.
